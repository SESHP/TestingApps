## 📋 Требуемые действия

### 1. Установка переменных окружения на Render.com

**КРИТИЧНО**: Необходимо установить следующие переменные окружения в настройках вашего сервиса на Render.com:

#### Обязательные переменные:

```
# Database (уже должны быть настроены)
DB_USER=your_db_user
DB_HOST=your_db_host
DB_NAME=alged_ref_db
DB_PASSWORD=your_secure_database_password
DB_PORT=5432

# НОВАЯ ПЕРЕМЕННАЯ - Telegram Bot Token
BOT_TOKEN=your_bot_token_from_botfather

# Node Environment
NODE_ENV=production
```

#### Опциональные (если используете):

```
# Telegram API (для мониторинга подарков)
TELEGRAM_API_ID=your_api_id
TELEGRAM_API_HASH=your_api_hash
TELEGRAM_SESSION=your_session_string
```

---

### 2. Как получить BOT_TOKEN

1. Откройте Telegram и найдите бота **@BotFather**
2. Отправьте команду `/mybots`
3. Выберите вашего бота
4. Нажмите **API Token**
5. Скопируйте токен (формат: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)
6. Установите его в переменную окружения `BOT_TOKEN` на Render.com

**⚠️ ВАЖНО:** Никогда не публикуйте BOT_TOKEN в репозитории! Это секретный ключ.

---

### 3. Настройка переменных окружения на Render.com

#### Шаг за шагом:

1. Откройте ваш проект на https://dashboard.render.com
2. Выберите ваш веб-сервис (backend)
3. Перейдите в **Environment** на левой панели
4. Нажмите **Add Environment Variable**
5. Добавьте каждую переменную:
   - **Key**: `BOT_TOKEN`
   - **Value**: ваш токен от BotFather
6. Нажмите **Save Changes**
7. Render автоматически перезапустит сервис

**Скриншот настройки:**
```
Environment Variables
├─ DB_PASSWORD = ***********
├─ DB_USER = buzeoff
├─ DB_HOST = your-db-host
├─ DB_NAME = alged_ref_db
├─ DB_PORT = 5432
├─ BOT_TOKEN = *********** (ДОБАВИТЬ)
└─ NODE_ENV = production
```

### 6. Миграция с локальной разработки

Если вы работаете локально:

1. Создайте файл `backend/.env` (НЕ коммитить в git!):

```bash
# backend/.env
PORT=3001
NODE_ENV=development

DB_USER=your_local_db_user
DB_HOST=localhost
DB_NAME=alged_ref_db
DB_PASSWORD=your_local_db_password
DB_PORT=5432

BOT_TOKEN=your_bot_token_here
```

2. Добавьте `.env` в `.gitignore` (если еще нет):

```bash
# .gitignore
*.env
.env
.env.local
```

3. Запустите сервер:

```bash
cd backend
npm install
npm start
```

### 8. Troubleshooting

#### Проблема: Ошибка "DB_PASSWORD environment variable is required in production"

**Решение:** Установите переменную `DB_PASSWORD` на Render.com

---

#### Проблема: Ошибка "BOT_TOKEN not configured"

**Решение:**
1. Проверьте что переменная `BOT_TOKEN` установлена
2. Перезапустите сервис на Render
3. Проверьте логи на наличие ошибок

---

#### Проблема: WebSocket ошибка "Authentication failed"

**Решение:**
1. Проверьте что BOT_TOKEN правильный
2. Убедитесь что фронтенд обновлен (передает initData)
3. Проверьте что используете правильный бот

---

#### Проблема: API возвращает 401 Unauthorized

**Решение:**
1. Проверьте что фронтенд передает initData в заголовках
2. Проверьте что BOT_TOKEN установлен на сервере
3. Попробуйте очистить кеш браузера
